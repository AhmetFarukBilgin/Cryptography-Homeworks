# Cryptography Homeworks

This repository contains coding exercises and assignments for the Cryptology (Kriptoloji) course term. Each subfolder holds a small, self-contained task or experiment completed during the semester.

## Current contents
- **Euclid Alg/**: Implements the Euclidean algorithm for computing the greatest common divisor (GCD) of two integers. The `alg.py` module provides the core logic and iteration counter, while `main.py` offers a simple CLI prompt for user input.

## Running the Euclid example
Prerequisites: Python 3.8+ installed and available on your PATH.

```bash
# From the repository root
cd "Euclid Alg"
python main.py
```
You will be prompted for two integers; the program prints the GCD and the number of iterations performed.
